小智 AI：零预算 Gemini + Netlify Functions

项目文件：
- index.html：手机聊天界面
- netlify/functions/chat.mjs：安全后端，调用 Gemini API
- netlify.toml：Netlify 部署配置

默认模型：gemini-3.8-flash（部署前请在 Google AI Studio 的模型可用性/免费层页面确认账号与地区额度）。
环境变量：
- GEMINI_API_KEY：Google AI Studio API Key（必须）
- GEMINI_MODEL：可选，默认 gemini-3.8-flash

部署要求：
Netlify Functions 需要使用 Git 连接部署或 Netlify CLI。单独用 Netlify Drop 上传静态 HTML 不会部署这个函数。
1. 解压 zip。
2. 把 index.html、netlify.toml 和 netlify 文件夹放在 GitHub 仓库根目录。
3. Netlify → Add new project → Import an existing project → 连接 GitHub 仓库并部署。
4. Netlify → Project configuration → Environment variables → Add variable：
   Key: GEMINI_API_KEY
   Value: 你的 Gemini API Key
5. 保存后重新部署。
6. 可选：增加 GEMINI_MODEL=gemini-3.8-flash。
7. 测试网站对话。

重要：
- API Key 不要发给别人，不要放进网页文件或公开仓库。
- 免费层仅限部分模型，有速率/每日配额，可能随地区、账号和时间变化。
- 免费层请求内容可能用于改进 Google 产品；不要输入密码、隐私或机密。
- 不要开通 Cloud Billing 或付费层，以保持 API 预算目标为 $0。达到免费配额后等配额重置，不会自动变成无限免费。
- Netlify 免费计划也有自己的额度与限制。
